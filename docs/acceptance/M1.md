## 实现范围

| 设计项 | 位置 |

| LocalFile 导入（16 MiB 上限，先校验后建 Profile） | `subscriptions/import.rs`、`app/pipeline.rs` |

| 内核二进制 SHA256 + `-v` 校验、geodata 播种 | `cores/mihomo/binary.rs` |
| 挂起创建 → Job Object（KILL_ON_JOB_CLOSE）→ 恢复 | `cores/mihomo/process.rs` |
| 控制器（/version、/proxies、选择、组测速、关闭连接） | `cores/mihomo/controller.rs` |
| 就绪判定（/version + mixed-port，15 s） | `app/runtime.rs` |
| 节点选择记忆 `selection.json` 与启动后恢复 | `app/handlers.rs`、`app/runtime.rs` |

| generation 丢弃过期结果、切换 Profile 单事务 | `app/handlers.rs` |
