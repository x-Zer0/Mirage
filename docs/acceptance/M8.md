# M8：Windows 安装包与分发

日期：2026-10-17。环境：Windows 11 x64，Rust 1.95.0 stable-msvc；官方 Mihomo Meta v1.19.32 with_gvisor；Inno Setup 6.4.3、cargo-about 0.9.2。未新增或运行单元测试，未记录成本。

## 实现范围

- `scripts/package.ps1`：锁定 workspace release 构建，应用 / helper 版本一致校验，打包文件完整性及固定核心 / geodata SHA256 校验，cargo-about 生成第三方依赖许可清单，Inno 编译，安装器及入包文件哈希输出。
- `scripts/core-assets.psd1`：下载和打包共用固定资源清单；核心固定值同时与 `ipc/src/binary.rs` 核对。滚动 geodata 不接受未经更新清单的替换。
- `packaging/Mirage.iss`：当前用户安装，无需管理员权限；欢迎 / 安装说明 / 目录 / 可选桌面图标 / 进度 / 完成引导；开始菜单与 Windows 应用列表卸载入口。
- 主程序、mirage-service.exe、官方 Mihomo 和四份 geodata 一起入包。安装阶段不注册服务；首次启用 TUN 时说明并 UAC，服务过旧或归属路径不同则要求更新。UAC 取消按 Cancelled 处理，保留原模式。
- 新增正常退出命令及实例事件，安装 / 升级 / 卸载等待系统代理恢复和核心停止；残留恢复日志也会处理。卸载仅处理属于当前路径 / 用户的服务，服务卸载取消或失败则停止应用卸载；保留订阅、账号及设置。
- Windows x64 静态链接 CRT，避免干净系统缺少 VCRUNTIME140.dll。Slint 继续使用 software renderer。
- 许可证材料：Mihomo GPLv3 原文与精确版本源码地址、Slint Royalty-free 2.0 原文及组件列表、Rust 运行时依赖 HTML 清单、Lucide、geodata / MaxMind / CC BY-SA 4.0、Inno Setup 和中文翻译归属。当前未签名。

| 文件完整性 | 安装目录中 17 个 payload 文件 SHA256 全部匹配，含应用、helper、五个核心资源及许可材料 |

## 仍需其他环境验收

- 干净 Windows 10 1809 / Windows 11 无 Rust / MSVC 环境，从零安装后完整执行 M1～M4（本地 YAML、URL、自由猫登录及更新）的实网流程。
- 没有服务时第一次开启 TUN、确认 / UAC 取消、安装成功后继续启用；升级后受保护副本更新；标准用户使用另一管理员凭据授权。
- 本应用路径安装的服务在卸载时 UAC 取消 / 成功，以及 Windows 重启、注销后的路由恢复。完整 TUN / UDP / IPv6 仍沿用 M7 的实机验收记录和限制。
- 已有开发路径服务不误卸载及保留用户设置已验证；仍需另一 Windows 用户的服务归属隔离、重装后的完整配置恢复验收。

编译、静态检查和本机安装检查不能替代上述独立系统与网络验收。构建方法、工具来源与许可、安装 / 升级 / 卸载行为见 [packaging.md](../packaging.md)。
