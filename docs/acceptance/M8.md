# M8：Windows 安装包与分发

日期：2026-10-17。环境：Windows 11 x64，Rust 1.95.0 stable-msvc；官方 Mihomo Meta v1.19.32 with_gvisor；Inno Setup 6.4.3、cargo-about 0.9.2。未新增或运行单元测试，未记录成本。

## 实现范围

- `scripts/package.ps1`：锁定 workspace release 构建，应用 / helper 版本一致校验，打包文件完整性及固定核心 / geodata SHA256 校验，cargo-about 生成第三方依赖许可清单，Inno 编译和便携 ZIP 同次输出，两种产物及各自入包文件哈希输出。
- `scripts/core-assets.psd1`：下载和打包共用固定资源清单；核心固定值同时与 `crates/mirage-ipc/src/binary.rs` 核对。滚动 geodata 不接受未经更新清单的替换。
- `packaging/Mirage.iss`：当前用户安装，无需管理员权限；欢迎 / 安装说明 / 目录 / 可选桌面图标 / 进度 / 完成引导；开始菜单与 Windows 应用列表卸载入口。
- 主程序、mirage-svc.exe、官方 Mihomo 和四份 geodata 一起入包。安装阶段不注册服务；首次启用 TUN 时说明并 UAC，服务过旧或归属路径不同则要求更新。UAC 取消按 Cancelled 处理，保留原模式。
- 新增正常退出命令及实例事件，安装 / 升级 / 卸载等待系统代理恢复和核心停止；残留恢复日志也会处理。卸载仅处理属于当前路径 / 用户的服务，服务卸载取消或失败则停止应用卸载；保留订阅、账号及设置。
- Windows x64 静态链接 CRT，避免干净系统缺少 VCRUNTIME140.dll。Slint 继续使用 software renderer。
- 许可证材料：Mihomo GPLv3 原文与精确版本源码地址、Slint Royalty-free 2.0 原文及组件列表、Rust 运行时依赖 HTML 清单、Lucide、geodata / MaxMind / CC BY-SA 4.0、Inno Setup 和中文翻译归属。当前未签名。

## 2026-10-18：安装版与便携版同时产出

本次仅修改 PowerShell 打包流程及文档，未修改应用运行逻辑、数据位置或 TUN 权限流程。`Initialize-Payload` 统一准备应用、helper、固定核心 / geodata 和许可证；同一次 `pwsh -File scripts/package.ps1` 构建后编译 Inno 安装器，并使用 PowerShell 自带 `Compress-Archive` 输出便携 ZIP。两个产物分别生成 SHA256。

ZIP 顶层为 `Mirage/`，公共文件与安装版一致；额外附带 `README-portable.txt`，独立 `payload-sha256.txt` 覆盖此说明。安装器专用 `app.ico`、卸载器、构建目录和用户数据均不进入 ZIP。便携版数据仍在 `%LOCALAPPDATA%\Mirage`，与安装版共用；凭据仍使用 Windows 凭据管理器 / 当前用户 DPAPI。首次 TUN 安装服务、UAC 取消、服务归属路径更新沿用现有实现。
