# M12：UWP 回环豁免

日期：2026-10-22。环境：Windows 11 Enterprise LTSC 2024 x64，Rust stable-msvc。设计依据 [iteration-2-design.md](../iteration-2-design.md) §6。未新增或运行单元测试。

## 实现范围

- `platform/windows/loopback.rs`：FirewallAPI 封装：`list`（枚举 AppContainer，SID 转字符串，`@{…}` 显示名用 `SHLoadIndirectString` 解析，失败回退为包名；按显示名排序）、`exempt_sids`（读取当前豁免，含不在列表中的 SID）、`set_exempt`（校验 `S-1-15-2-` 格式，`ConvertStringSidToSidW` 转换后整体写入，逐个 `LocalFree`）。
- `platform/windows/service.rs`：抽出通用 `run_elevated(exe, args) -> 退出码`，服务安装 / 卸载改为复用。
- `main.rs`：`Mirage.exe --set-loopback-exempt <SID>...` 子命令，位于单实例检查和 UI 初始化之前，退出码即结果。
- `app/loopback.rs`：打开弹层时后台读取列表；保存时目标列表 = 当前豁免 − 取消勾选 + 新勾选（不在列表中的豁免保持不变），先直接写入，`ERROR_ACCESS_DENIED` 时经 UAC 启动提权子进程；UAC 取消按“已取消”提示、不改变状态；命令行超过 32,000 字符时提示“选择的应用过多”。保存后重新读取列表。操作日志“设置 UWP 回环豁免”。
- `ui_bridge/loopback_editor.rs` + `ui/pages/loopback.slint`：UI 线程工作副本；搜索（显示名 / 包名）、对当前搜索结果“全选 / 全不选”、勾选就地更新不跳动、“已勾选 N / M”、保存 / 取消；读取中显示“正在读取应用列表…”。
- 设置页“网络”分区新增“UWP 回环豁免…”按钮与说明（TUN 模式不需要）。
- `windows` crate 新增 feature `Win32_NetworkManagement_WindowsFirewall`（`Win32_Security_Authorization`、`Win32_UI_Shell` 已有）。
- 文档：DESIGN §17.1 设置页；iteration-2-design §6.3 / §6.4 / §9 实测结论；根 README 功能列表。
