# 账号订阅并入配置

日期：2026-10-17；环境：Windows 11、Rust 1.95.0 stable-msvc、Slint 1.18.1。当前产品设计见 [DESIGN.md §6.1 / §17.1](../DESIGN.md)，自由猫协议及账号交互见 [ZIYOUMAO.md §6.5](../ZIYOUMAO.md)。M4 原记录保留为历史证据，不代表当前界面。

## 定稿范围

| 功能 | 当前行为 |
| --- | --- |
| 导航 | 总览、配置、节点、设置、诊断五页；不重复显示顶部菜单名，节点未连接提示上下左右居中；删除独立账号菜单 |
| 配置来源 | `LocalFile` / `RemoteUrl` / `ProviderAccount`；账号协议由 `AccountProvider` 分发，复用通用配置管线 |
| 添加自由猫账号 | 始终保持添加文案；单账号，新登录成功覆盖原账号并沿用配置，登录失败保留原会话 |
| 登录弹窗 | 420px 宽、上下 40px 留白；行内标签与输入框、间距 6px；等宽取消/登录；标题右侧“从自由猫导入”；两处 Lucide 问号悬浮说明 |
| 原客户端导入 | 只读取配置，生成独立本地配置；不导入凭据、不覆盖账号、不自动更新 |
| 配置设置 | 400px 右侧抽屉，合并账号信息、正文与标题左右对齐；下载出站与下拉框同行，更新间隔为 0～720 整数文本框 |
| 账号显隐 | 默认脱敏；眼睛手动切换，无提示、无自动隐藏计时；关闭抽屉、覆盖账号或删除配置后清除完整显示 |
| 刷新信息 | 位于眼睛后，验证会话、刷新快照与缓存 URL、同步用量；不下载或应用配置 |
| 列表刷新 | 更新订阅，下载/解码/校验后应用；账号来源在更新过程中也读取最新快照与 URL |
| 删除 | 统一使用配置删除，先二次确认；账号配置连同身份、会话、订阅地址、账号元数据及本地配置文件清理；使用中先断开 |
| 凭据 | 完整邮箱使用 SecretStore 固定键 `account/<id>/identity`；元数据保持脱敏，密码不保存；没有旧邮箱缺失时的兼容提示 |

## 验证范围

使用 `target/layout-preview` 加载实际 `crates/mirage-app/ui/app.slint` 的独立界面，账号与配置为 `example.com` 示例数据；不读取真实凭据、不启动代理内核、不提交登录、不执行原客户端导入或真实删除。

- 1000×680：检查登录弹窗比例、上下留白、行内表单、等宽按钮、问号居中；悬浮查看两种说明，确认单一提示表面、无两侧多余空白。
- 1000×680：检查抽屉宽度、账号标题、邮箱/眼睛/刷新顺序、订阅设置；用示例邮箱验证手动显隐、39 秒后仍显示完整邮箱无提示，以及关闭重开后的脱敏状态。
- 760×520：检查 420px 登录弹窗完整显示、留白与居中不变，取消/登录无裁切；抽屉保持 400px，内容随可用高度滚动，底部安全调整可完整查看。
- 本次抽屉检查：正文、分隔线、右侧按钮与标题区边缘对齐；节点未连接提示在主内容区上下左右居中。
- 本次更新间隔文本框：空值、1.5、721 提示并禁用保存；0、720 可保存。输入控件使用数字类型，键入和粘贴仅接受数字。
- 静态核对：登录覆盖、统一删除及凭据清理路径；列表刷新与账号刷新分开；无眼睛 Tooltip 或自动隐藏 Timer。

当前布局预览不替代真实登录、订阅更新、覆盖账号和删除数据的端到端验证；既有历史协议验证仍见 M4 及 AES 分析记录。未新增或运行单元测试。
