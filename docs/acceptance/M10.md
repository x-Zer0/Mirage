# M10：规则页框架与 Hosts

日期：2026-10-22。环境：Windows 11 x64，Rust stable-msvc；官方 Mihomo Meta v1.19.32。设计依据 [iteration-2-design.md](../iteration-2-design.md) §1、§2。未新增或运行单元测试。

## 实现范围

- 侧栏：在“节点”和“设置”之间新增“规则”页（Lucide `list-filter`，lucide-static 1.57.0）；页码顺延为 规则 3、设置 4、日志 5，`app.slint` 中日志页刷新判断同步改为 5。托盘与 Rust 侧没有写死页码。
- `ui/pages/rules.slint`：“附加规则 / Hosts”两个标签，标签状态保存在主窗口中；附加规则标签暂为占位，M11 实现。
- Hosts 标签（页签名“追加 Hosts”）：启用开关、说明图标、已保存域名数、hosts 文件格式编辑框（带示例占位）、按行错误列表、保存 / 放弃修改；校验中按钮禁用并显示“正在校验…”。
- `overrides/hosts.rs`：解析 `IP 域名…`，`#` 注释；支持精确域名、`*.`、`+.`；同一域名的多行合并为多个地址；上限 2000 行、单行 1024 字符、域名 253 / 标签 63 字符；错误带行号，最多列出 50 条。
- `storage/layout.rs`：`overrides/` 目录随数据目录创建，`hosts.txt` 原子写。
- `settings.json`：`custom_hosts_enabled`，默认 true。
- `UserOverlay.hosts`：合并进运行配置 `hosts`（同键以用户为准，单地址写字符串，多地址写列表）；存在 `dns` 块时写 `dns.use-hosts: true`。
- `app/hosts.rs`：保存流程 解析 → 覆写有变化时对选中配置的活动版本 `-t` → 写文件与设置 → 已连接时热重载；只改注释 / 空白不校验、不重载。操作日志“保存 Hosts”。
- `app/overlay.rs`：覆写热重载失败且无法回退（Hosts 文件已保存）时记下失败的覆写，不自动重试，提示用户检查后重新保存。
- 文档：DESIGN §9.3 覆写白名单、§13 `overrides/`、§17.1 页面表与六页导航；iteration-2-design §2 M10 定稿说明。
