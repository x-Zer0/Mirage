# Country flag assets

Unmodified 4:3 SVGs from flag-icons v7.5.0:
https://github.com/lipis/flag-icons/tree/v7.5.0/flags/4x3

Copyright (c) 2013 Panayiotis Lipiridis. MIT license:
../../../../packaging/licenses/flag-icons-MIT.txt

The build embeds these files in the executable. The node UI resolves leading
Unicode regional indicator pairs to lowercase country codes, so country flags
do not depend on the installed Windows emoji font. Original node names are
preserved for filtering and controller requests.
