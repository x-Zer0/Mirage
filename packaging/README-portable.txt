Mirage 便携版（免安装 ZIP）
适用系统：Windows 10 1809+ / Windows 11 x64。

开始使用
1. 将 ZIP 完整解压到固定目录，再运行 Mirage.exe。不要直接在压缩包内运行。
2. 保留同目录的 mirage-service.exe、core 和 licenses 文件夹。
3. 普通订阅、节点切换、测速、HTTP / SOCKS 和系统代理均可使用，无需安装主程序。

用户数据与凭据
设置、订阅、缓存和日志仍保存到 %LOCALAPPDATA%\Mirage，与同一 Windows 用户的安装版共用。
本包是主程序免安装分发，不会将用户数据迁移到程序旁；同一用户下仅运行一个 Mirage 实例。
账号及订阅凭据使用 Windows 凭据管理器 / 当前用户 DPAPI 保护。
复制程序目录到另一台电脑或换 Windows 用户，不会自动迁移这些凭据，需要重新登录或导入。

TUN 与开机启动
首次开启 TUN 时仍会提示安装辅助服务，确认后请求 Windows 管理员授权。
服务安装到 %ProgramFiles%\Mirage\service，TUN 工作数据保存到 %ProgramData%\Mirage\tun-home。
解压或普通运行不会安装服务；取消授权则保持原有连接方式。
启用开机启动会写入当前用户启动项，路径应保持固定。
移动目录后手动启动一次可修复已启用的启动项；下次开启 TUN 时可能需要重新授权更新服务归属路径。
安装版和便携版共用同名辅助服务，切换运行路径时可能需要再次授权更新。

更新与移除
更新前从托盘正常退出 Mirage，等待系统代理恢复及内核退出，再用新版本完整替换程序文件。
也可运行 .\Mirage.exe --quit 请求正常退出；不要在仍运行时覆盖文件。
删除前先在设置中关闭开机启动；使用过 TUN 的，请先关闭 TUN 并卸载辅助服务（需要管理员授权）。
然后从托盘正常退出，再删除整个程序文件夹。只删除文件夹不会自动移除服务、启动项或用户数据。
同一用户的安装版也使用上述数据和服务；移除前请确认它们是否仍需保留。

完整性与许可
下载时可用 ZIP 同名 .sha256 核对压缩包；payload-sha256.txt 列出包内文件的 SHA256。
第三方许可及源码获取方式见 THIRD-PARTY-NOTICES.txt 和 licenses 文件夹。
当前程序未进行 Authenticode 签名。
